# 报告版面

`report.mjs` 出的是**基线** —— 保证每次都不难看。
要当门面作品发出去时手写，手写才可能"这次特别好"。

手写时数据一律从 `an.json` 取。**一个数都不许自己编**，这是这类内容唯一的立身之本。

---

## 结构

八个 plate，顺序有讲究：

| # | 内容 | 为什么放这个位置 |
|---|---|---|
| 01 | **指纹**（findings） | 最硬的信息放最前。漂移排在签名和手艺前面 |
| 02 | 字距曲线 | 一张图就能看懂，适合承接开头 |
| 03 | 字体阶梯 | 用真实字号渲染的样张，读者能直接感受 |
| 04 | 色板 | 信息量最大，但也最"标准"，放中间 |
| 05 | 动效 | 缓动曲线画出来最直观 |
| 06 | 层级梯 | 冷门但有意思 |
| 07 | 形状与尺度 | 补完 |
| 08 | 可带走的 token | 收尾给实用价值 |

数据不足的 plate **直接不渲染**，不要留一个空壳说"暂无数据"。

---

## 开头必须有的三样

1. **置信度徽章** —— A/B/C 和它的说明。读者要先知道这份报告的性质
2. **一句话说清方法** —— "不看截图，直接读 CSSOM 把它量出来"。
   这句话是这类内容的差异点，别省
3. **统计数字** —— token 数、元素数、发现数。让读者知道这不是随手看看

## 视觉

基线模板走的是**技术解剖图 / specimen sheet** 的路子：冷色纸、双墨、
硬边框的 plate、等宽字承载所有数值、批注色标记异常。

几个不要：

- **不要做成被解剖那个站的样子**。用 Linear 的配色展示 Linear 的配色是偷懒，
  而且色板会看不清 —— 报告需要中性底才能让色标显色准
- **不要用暖奶油底 + 衬线大标题 + 陶土色点缀**，也不要**近黑底 + 一个荧光绿**。
  这两套是 AI 生成设计的重灾区，一眼就能认出来
- **不要给每个 section 配 emoji**

批注色（`--mark`）取**目标站品牌色的色相**，但明度和彩度锁死：
`oklch(50% 0.17 <H>)` / 深色模式 `oklch(74% 0.15 <H>)`。
这样每份报告带着被解剖对象的色调，又不会因为对方用了荧光色而变得读不了。

## 图表

**02 这张图是自适应的**：有绑字号的字距就画字距曲线，没有就改画行高比。
Tailwind v4 这类把字距做成独立命名 `--tracking-*`（不绑字号）的系统，
画字距会得到一条压在 0 上的平线 —— 没有任何信息，那时行高曲线才是有话说的那张。

**字距模式**下按 token 族分线，台阶处画竖虚线标注。台阶是主角 ——
没检出台阶就说明这个站字距是乱的，那也是结论，照画。
**行高模式**下曲线往下走 = 字越大排得越紧，走平 = 所有字号共用一个行高。

**缓动曲线**画成 `M0,S C x1,(1-y1)S x2,(1-y2)S S,0` 的小方格阵列，
在用的高亮，死库存的压灰。18 个格子里只有 1 个亮着，这张图本身就是那条发现。

**梯子类**（层级、时长、间距）用横条 + 等宽数字。层级的条宽要开方压缩
（`pow(v/max, 0.28)`），否则 10000 那一档会把其余全压成看不见。

宽内容一律套 `overflow-x:auto` 的容器，页面本体不许横向滚动。

## 写作

**句子要有数**。「这个站很克制」是废话，「只用了 4 档动画时长，最长 0.25s」才是信息。

**敢说难听话**。发现一个站做得糙就照直说 —— 吹捧稿没人看，
而且这类内容的可信度全靠敢下负面判断。反过来，
夸也要夸在具体的地方（"字距在 32px 处硬切换"），不要夸气质。

**漂移那一节的语气是中性的**，不是嘲讽。系统和实现分家是每个长期项目的必然，
指出来是有价值的观察，写成"看他们多菜"就掉价了。

**边界要写在明面上**：
- 只采了一个视口 → 不许写"响应式做得好"
- `stylesheetsBlocked > 0` → 交互态数据不完整，footer 里标注
- 置信度 C → 开头就说"这是页面统计，不是系统解剖"

## 主题

三态都要顾：`:root` 定义完整浅色 token，
`@media (prefers-color-scheme: dark)` 里用 `:root:not([data-theme="light"])` 包一层，
再加 `:root[data-theme="dark"]` 让显式切换在两个方向都生效。

`body` 必须显式设 `background`，否则会借宿主的底色。
**任何颜色都不许只定义在 media 或 `[data-theme]` 块里** ——
那是"一个主题的字配另一个主题的底"这个经典 bug 的来源。

色标 chip 一律加 `border: 1px solid var(--chip-edge)`，
否则接近底色的色块（近黑、近白）会整个消失。
